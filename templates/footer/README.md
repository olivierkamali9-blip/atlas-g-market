# Standard Footer "Powered by G-Tech" - Guide d'intégration Universel

Ce dossier contient les composants et scripts officiels pour garantir que **chaque application de l'écosystème G-Tech HQ** intègre la signature institutionnelle "Powered by G-Tech", le copyright unifié et les accès aux mentions légales.

---

## 1. Options d'intégration

### Option A : Composant React / TypeScript (Recommandé pour projets React/Next.js)
Copier le composant React prêt à l'emploi situé dans `templates/footer/GTechFooter.tsx` dans votre projet frontend (`src/components/GTechFooter.tsx`).
