# Spécifications Techniques Finales - Atlas G-market

## Architecture Globale
- **Backend**: Node.js + Express (API RESTful)
- **Base de données**: PostgreSQL (schéma flexible pour offres/demandes)
- **Frontend**: React + TypeScript (Next.js pour le SSR)
- **DevOps**: Docker + GitHub Actions (CI/CD)
- **Hébergement**: Vercel (frontend) + Railway (backend + DB)
