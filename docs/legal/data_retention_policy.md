# Politique de Rétention des Données - Atlas G-market

## 1. Durée de conservation
| Type de données          | Durée       | Base légale          |
|--------------------------|-------------|----------------------|
| Comptes utilisateurs     | 3 ans       | RGPD Art. 5(1)(e)    |
| Historique des annonces  | 1 an        | Droit commercial     |
| Messages privés          | 6 mois      | RGPD Art. 5(1)(c)    |
| Logs techniques          | 3 mois      | Sécurité             |
| Données de paiement      | 5 ans       | Obligation légale    |

## 2. Suppression automatique
- Les données sont supprimées automatiquement à l'expiration de leur durée de conservation
- Un email de confirmation est envoyé 1 mois avant suppression

## 3. Exceptions
- Conservation prolongée si :
  - Obligation légale (ex: litige en cours)
  - Demande d'une autorité judiciaire
  - Consentement explicite de l'utilisateur

## 4. Procédure de suppression manuelle
1. Demande via le formulaire RGPD
2. Vérification de l'identité
3. Suppression sous 30 jours
4. Confirmation par email

## 5. Anonymisation
- Les données anonymisées sont conservées indéfiniment pour les statistiques
- Impossible de ré-identifier les utilisateurs
