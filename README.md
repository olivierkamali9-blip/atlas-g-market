# Atlas G-Market

**Atlas G-Market** est une plateforme tout-en-un permettant de mettre en relation offre et demande dans tous les domaines : produits neufs ou d'occasion, services, emplois, etc. L'application offre un espace sécurisé pour discuter, publier et découvrir des opportunités adaptées à vos besoins.

## 🚀 Stack Technique

- **Backend** : Node.js + Express + TypeScript
- **Base de données** : PostgreSQL (via Docker)
- **Tests** : Jest (unitaires, intégration, QA)
- **CI/CD** : GitHub Actions
- **Déploiement** : Vercel (frontend) + Docker (backend)
- **Outils** : ESLint, Prettier, Nodemon
