# Atlas G-market Backend

Backend pour **Atlas G-market**, une plateforme de mise en relation entre offre et demande (produits, emplois, services, etc.). Ce projet est développé en TypeScript avec Express et MongoDB.

## 🚀 Fonctionnalités principales
- **Gestion des annonces** : Création, lecture, mise à jour et suppression d'annonces
- **Système de modération** : Suivi des actions avec logs d'audit détaillés
- **Authentification sécurisée** : JWT pour les utilisateurs
- **Validation des données** : Contrôle des entrées utilisateur
- **API RESTful** : Endpoints standardisés pour une intégration facile

## 🛠 Stack technique
- **Langage** : TypeScript
- **Framework** : Express.js
- **Base de données** : MongoDB (avec Mongoose)
- **Authentification** : JWT (JSON Web Tokens)
- **Sécurité** : Helmet, CORS, validation des entrées
- **Logging** : Winston pour les logs applicatifs
- **Tests** : Jest + Supertest
- **Outils** : ESLint, Prettier, Nodemon
